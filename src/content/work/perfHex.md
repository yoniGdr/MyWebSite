##### Presentation : 

Dans le cadre de mon mémoire en informatique à l’Université de Lille, j’ai intégré Capgemini, une Entreprise de Services du Numérique (ESN) qui accompagne des organisations de divers secteurs dans leur transformation digitale. J’ai eu l’opportunité d’y travailler pour un nouveau client, avec pour mission de concevoir et développer, en autonomie, une application sur mesure pour un préparateur et coach de basket pro souhaitant optimiser la gestion de ses programmes et améliorer le suivi de ses athlètes.

Ce projet s’inscrivait dans une démarche de transformation numérique, avec l’objectif de remplacer des processus manuels et fragmentés par une solution intégrée, centralisant la gestion des programmes, des tests et des communications avec les sportifs.

##### 🚀 Stack Technique

**Frontend** (Web)

- **React + Vite.js** : pour la création d’interfaces dynamiques et performantes

- **Figma** : conception des maquettes UI/UX

- **Axios** : gestion des requêtes HTTP

**Backend**

- **Node.js + Express.js** : API RESTful robuste et évolutive

- **MySQL** : base de données relationnelle pour la gestion des programmes, séances et utilisateurs

**Méthodologie & Outils**

- **Git** : gestion de versions

- **Jira** : gestion de projet agile, organisation en sprints

- **MVP** : conception itérative avec incréments fonctionnels

- **Tests unitaires (préparation)** : architecture pensée pour la maintenabilité

**Mobile (perspective future)**

- **React Native** : envisagé pour proposer une application mobile cohérente avec la version web
